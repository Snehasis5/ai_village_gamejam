Village Scope

Read and mine AI Village transcripts straight from Hugging Face, or from a file you downloaded.

Data source

Create one at huggingface.co/settings/tokens (type: Read). Your account must already be approved for the dataset. The token is sent only to Hugging Face.

Works with village-transcript.json and any *.jsonl.gz table (e.g. chat_messages.jsonl.gz). The file is read here in your browser and never uploaded.

Field mapping

Guessed from the columns. Change if the transcript looks wrong.

Case finder

Preset patterns for behaviours worth studying. On Hugging Face they run as a server search; on a local file, as a regex across everything loaded.
